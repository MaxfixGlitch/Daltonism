# Цветомер

Небольшой русскоязычный адаптивный сайт с учебной экранной пробой по принципу подбора цвета в аномалоскопе Рэлея. Пользователь сохраняет лучший вариант в шести повторах; каждый следующий начинается с предыдущей настройки. Результат показывает медианное значение и разброс повторных ответов, не сравнивая их с медицинскими нормами.

## Запуск

Это статический сайт: откройте `index.html` в браузере или запустите любой статический HTTP-сервер из корня репозитория, например:

```sh
python3 -m http.server 8000
```

## Как устроена проба

- Перед началом нужно отметить чек-лист условий: отключить автояркость/фильтры, убрать блики и сохранить настройки экрана.
- В каждом из шести повторов пользователь настраивает экранную смесь и сохраняет наиболее похожий вариант. Следующий повтор начинает с медианы предыдущих выборов и предыдущей яркости.
- Опорный жёлтый цвет построен на той же экранной RGB-линии смешения, что и регулируемое поле, поэтому его можно визуально достичь. Диапазон регулировки сужен до 30–70% красного — вокруг жёлтого, без крайних чисто-красного и чисто-зелёного цветов.
- Каждая попытка начинается немного в стороне от прошлого ответа; кнопку сохранения нельзя нажать, пока доля красного не изменена хотя бы на один шаг.
- Результат показывает медианное положение ползунка и разброс шести ответов. Этот разброс — повторяемость личных выборов, а не клиническая ширина диапазона совпадений; медицинских порогов или определения типа нет.
- Кнопки `−` и `+`: короткое нажатие меняет смесь на один процентный шаг; удержание постепенно ускоряется. Поддерживается сенсорное управление.

## Важное ограничение

Это не медицинский тест и не цифровая копия калиброванного аномалоскопа. Значения RGB на разных телефонах заметно различаются; результат зависит от дисплея, настроек экрана и освещения. Сайт не определяет диагноз или вид дальтонизма и рекомендует обратиться к офтальмологу/оптометристу для достоверной оценки.
